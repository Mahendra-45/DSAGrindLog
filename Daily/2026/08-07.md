## Add Two Integers — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Math
- **Link**: [Problem](https://leetcode.com/problems/add-two-integers/)

**Approach**:
Direct addition of the two inputs — no edge cases to handle beyond returning the sum.

**Time**: O(1) | **Space**: O(1)

```cpp
class Solution {
public:
    int sum(int num1, int num2) {
        return num1 + num2;
    }
};
```
