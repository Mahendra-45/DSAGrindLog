## Merge Strings Alternately — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Two Pointers, String
- **Link**: [Problem](https://leetcode.com/problems/merge-strings-alternately/)

**Approach**:
Loop up to the length of the longer string, appending a character from `word1` then `word2` at each index whenever that index is still within bounds for the respective string, naturally handling strings of unequal length.

**Time**: O(n + m) | **Space**: O(1) extra (excluding the output string)

```cpp
class Solution {
public:
    string mergeAlternately(string word1, string word2) {
        string ans = "";
        char a;
        int n = max(word1.size(), word2.size());
        for (int i = 0; i < n; i++) {
            if (word1.size() - 1 >= i) {
                a = word1[i];
                ans.push_back(a);
            }
            if (word2.size() - 1 >= i) {
                a = word2[i];
                ans.push_back(a);
            }
        }
        return ans;
    }
};
```

## Plus Minus — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/plus-minus/problem)

**Approach**:
Single pass counting positives, negatives, and zeros, then divide each count by `n` to get the ratio. Counters are declared as `double` so the division isn't truncated to an integer.

**Time**: O(n) | **Space**: O(1)

```cpp
void plusMinus(vector<int> arr) {
    double pos = 0, neg = 0, zero = 0;
    int n = arr.size();
    
    for (int i = 0; i < n; i++)
    {
        if (arr[i] > 0)
            pos++;
        else if (arr[i] < 0)
            neg++;
        else 
            zero++;
    }
    
    cout << pos / n << endl;
    cout << neg / n << endl;
    cout << zero / n << endl;
}   
```

## Staircase — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Pattern Printing, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/staircase/problem)

**Approach**:
For each row `i`, print `n - 1 - i` leading spaces followed by `i + 1` hash characters, building a right-aligned staircase from top to bottom.

**Time**: O(n²) | **Space**: O(1)

```cpp
void staircase(int n) {
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < n - 1 - i; j++)
        {
            cout << " ";
        }
        for (int k = 0; k < i + 1; k++)
        {
            cout << '#';
        }
        cout << endl;
    }
}   
```

## Min-Max Sum — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/mini-max-sum/problem)

**Approach**:
Single pass tracking the running min, max, and total sum. The minimum possible sum of four elements is the total minus the largest value, and the maximum possible sum is the total minus the smallest value.

**Time**: O(n) | **Space**: O(1)

```cpp
void miniMaxSum(vector<int> arr) {
    int min = arr[0], max = arr[0];
    long int ans = 0;
    
    for (int i = 0; i < arr.size(); i++)
    {
        if (min > arr[i])
            min = arr[i];
        if (max < arr[i])
            max = arr[i];
        ans += arr[i];
    }
    
    cout << ans - max << " " << ans - min;
}
```
