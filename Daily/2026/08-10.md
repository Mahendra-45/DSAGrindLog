## Merge Strings Alternately — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Two Pointers, String
- **Link**: [Problem](https://leetcode.com/problems/merge-strings-alternately/)

**Approach**:
Loop up to the length of the longer string, appending a character from `word1` then `word2` at each index whenever that index is still within bounds for the respective string, naturally handling strings of unequal length.

**Time**: O(n + m) | **Space**: O(1) extra (excluding the output string)

```cpp
class Solution {
public:
    string mergeAlternately(string word1, string word2) {
        string ans = "";
        char a;
        int n = max(word1.size(), word2.size());
        for (int i = 0; i < n; i++) {
            if (word1.size() - 1 >= i) {
                a = word1[i];
                ans.push_back(a);
            }
            if (word2.size() - 1 >= i) {
                a = word2[i];
                ans.push_back(a);
            }
        }
        return ans;
    }
};
```
