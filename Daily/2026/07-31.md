## Maximum Subarray — LeetCode (Medium)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Divide & Conquer, Dynamic Programming
- **Link**: [Problem](https://leetcode.com/problems/maximum-subarray/)

**Approach**:
Kadane's Algorithm — keep a running sum, reset it to 0 whenever it goes negative, and track the maximum sum seen so far.

**Time**: O(n) | **Space**: O(1)

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int currSum = 0, maxSum = INT_MIN;
        for (int val : nums)
        {
            currSum += val;
            maxSum = max(currSum, maxSum);
            if (currSum < 0)
                currSum = 0;
        }
        return maxSum;
    }
};
```

## Majority Element — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Hash Table, Divide & Conquer, Sorting, Moore's Voting Algorithm
- **Link**: [Problem](https://leetcode.com/problems/majority-element/)

**Approach**:
Boyer–Moore Voting Algorithm — maintain a candidate and a counter, incrementing on a match and decrementing otherwise; a second pass confirms the final candidate appears more than n/2 times.

**Time**: O(n) | **Space**: O(1)

```cpp
class Solution {
public:
    int majorityElement(vector<int>& nums) {
        int freq = 0, ans = 0, count = 0;
        for (int i = 0; i < nums.size(); i++) {
            if (freq == 0)
                ans = nums[i];
            if (ans == nums[i])
                freq++;
            else
                freq--;
        }
        for (int val : nums) {
            if (ans == val)
                count++;
        }
        if (count > nums.size() / 2)
            return ans;
        else
            return 1;
    }
};
```

- Backfilled entry
- Fallback return (`1`) if no majority found is a bit off — fine here since the problem guarantees a majority element exists, but worth remembering for variants where it might not

## Best Time to Buy & Sell Stock — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Dynamic Programming
- **Link**: [Problem](https://leetcode.com/problems/best-time-to-buy-and-sell-stock/)

**Approach**:
Single pass — track the lowest price seen so far and update the best profit whenever the current price minus that minimum beats the running max.

**Time**: O(n) | **Space**: O(1)

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int profit = 0, bestBuy = prices[0];
        for (int i = 0; i < prices.size(); i++) {
            if (prices[i] > bestBuy)
                profit = max(profit, prices[i] - bestBuy);
            bestBuy = min(bestBuy, prices[i]);
        }
        return profit;
    }
};
```
