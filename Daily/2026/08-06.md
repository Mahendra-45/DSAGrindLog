## Final Value of Variable After Performing Operations — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Array, String
- **Link**: [Problem](https://leetcode.com/problems/final-value-of-variable-after-performing-operations/)

**Approach**:
Single pass — each operation string ("++X", "X++", "--X", or "X--") has its `+`/`-` sign at a fixed index (index 1), so checking that character directly tells you whether to increment or decrement, no need to parse the whole string.

**Time**: O(n) | **Space**: O(1)

```cpp
class Solution {
public:
    int finalValueAfterOperations(vector<string>& operations) {
        int x = 0;
        for (auto op : operations)
        {
            if (op[1] == '+')
                x++;
            else
                x--;
        }
        return x;
    }
};
```
