## Peak Index in a Mountain Array — LeetCode (Medium)

- **Status**: ✅ Solved
- **Revisit**: Yes
- **Topics**: Binary Search, Arrays
- **Link**: [Problem](https://leetcode.com/problems/peak-index-in-a-mountain-array/)

**Approach**:
Starts at the middle index and walks one step at a time toward the peak by comparing `arr[mid]` to its neighbors, moving right if the next element is bigger and left if the previous one is bigger, stopping once `mid` is greater than both neighbors.

**Time**: O(n) worst case | **Space**: O(1)

```cpp
class Solution {
public:
    int peakIndexInMountainArray(vector<int>& arr) {
        int left = 1, right = arr.size() - 2;
        int mid = left + (right - left) / 2;
        while (left <= right) {
            if (arr[mid] < arr[mid + 1])
                mid += 1;
            else if (arr[mid] < arr[mid - 1])
                mid -= 1;
            else
                return mid;
        }
        return -1;
    }
};
```

**Notes**:
- Backfilled entry
- Not true binary search — `left`/`right` are computed once but never updated inside the loop, so this is really a linear walk from the middle toward the peak rather than a halving search. Worst case is O(n), not O(log n). A true binary search version would move `left`/`right` by half each step based on the same `arr[mid]` vs `arr[mid+1]` comparison
