## Can Place Flowers — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Greedy, Array
- **Link**: [Problem](https://leetcode.com/problems/can-place-flowers/)

**Approach**:
Greedy single pass — at each empty plot, check if both neighbors (treating out-of-bounds as empty) are also empty; if so, plant a flower there and count it. Planting greedily as early as possible never blocks a better solution, since an earlier empty plot won't help future placements more than filling it now does.

**Time**: O(n) | **Space**: O(1)

```cpp
class Solution {
public:
    bool canPlaceFlowers(vector<int>& flowerbed, int n) {
        int size = flowerbed.size(), count = 0;
        for (int i = 0; i < size; i++)
        {
            if (flowerbed[i] == 0)
            {
                bool emptyLeft = (i == 0) || (flowerbed[i - 1] == 0);
                
                bool emptyRight = (i == size - 1) || (flowerbed[i + 1] == 0);
                
                if (emptyLeft && emptyRight)
                {
                    flowerbed[i] = 1;
                    count++;
                }
            }
        }
        return count >= n;
    }
};   
```
