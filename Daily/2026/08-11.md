## Greatest Common Divisor of Strings — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Math, String, GCD
- **Link**: [Problem](https://leetcode.com/problems/greatest-common-divisor-of-strings/)

**Approach**:
Key insight: if a common "divisor" string exists, concatenating `str1 + str2` must equal `str2 + str1` (otherwise no such string exists, return ""). If that check passes, the answer is the prefix of `str1` whose length is the GCD of the two string lengths.

**Time**: O(n + m) | **Space**: O(n + m) for the concatenation checks

```cpp
class Solution {
public:
    string gcdOfStrings(string str1, string str2) {
        if (str1 + str2 != str2 + str1)
            return "";
        int gcdStr = gcd(str1.length(), str2.length());
        return str1.substr(0, gcdStr);
    }
};
```

## Birthday Cake Candles — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/birthday-cake-candles/problem)

**Approach**:
Single pass tracking the tallest candle height and how many candles share that height, resetting the count to 1 whenever a taller candle is found.

**Time**: O(n) | **Space**: O(1)

```cpp
int birthdayCakeCandles(vector<int> candles) {
    int ans = INT_MIN, freq;
    
    for (auto val : candles)
    {
        if (ans < val)
        {
            ans = val;
            freq = 1;
        }
            
        else if (ans == val)
            freq++;
    }
    return freq;
}   
```

## Time Conversion — HackerRank

- **Status**: ✅ Solved
- **Revisit**: Yes
- **Topics**: String, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/time-conversion/problem)

**Approach**:
Extract hour, minute, second, and AM/PM period from fixed character positions in the string, then convert to 24-hour format: 12 AM becomes 00, and any PM hour other than 12 gets 12 added. The result is rebuilt with zero-padded fields.

**Time**: O(1) (fixed-length input string) | **Space**: O(1)

```cpp
string timeConversion(string s) {
    int hour = stoi(s.substr(0, 2));
    int minute = stoi(s.substr(3, 2));
    int sec = stoi(s.substr(6, 2));
    string period = s.substr(8, 2);
    
    if (period == "AM")
    {
        if (hour == 12)
            hour = 0;
    }
    else 
    {
        if (hour != 12)
            hour += 12;
    }
    
    stringstream result;
    result << setw(2) << setfill('0') << hour << ":"
           << setw(2) << setfill('0') << minute << ":"
           << setw(2) << setfill('0') << sec;
    return result.str();
}
```
