## Greatest Common Divisor of Strings — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Math, String, GCD
- **Link**: [Problem](https://leetcode.com/problems/greatest-common-divisor-of-strings/)

**Approach**:
Key insight: if a common "divisor" string exists, concatenating `str1 + str2` must equal `str2 + str1` (otherwise no such string exists, return ""). If that check passes, the answer is the prefix of `str1` whose length is the GCD of the two string lengths.

**Time**: O(n + m) | **Space**: O(n + m) for the concatenation checks

```cpp
class Solution {
public:
    string gcdOfStrings(string str1, string str2) {
        if (str1 + str2 != str2 + str1)
            return "";
        int gcdStr = gcd(str1.length(), str2.length());
        return str1.substr(0, gcdStr);
    }
};
```
