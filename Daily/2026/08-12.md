## Kids With the Greatest Number of Candies — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: Yes
- **Topics**: Array
- **Link**: [Problem](https://leetcode.com/problems/kids-with-the-greatest-number-of-candies/)

**Approach**:
Find the maximum candy count in the array first, then for each kid check whether their candies plus the extra candies would be at least that maximum.

**Time**: O(n) | **Space**: O(1) extra (excluding the output array)

```cpp
class Solution {
public:
    vector<bool> kidsWithCandies(vector<int>& candies, int extraCandies) {
        int n = candies.size();
        int maxCandy = *max_element(candies.begin(), candies.end());
        vector<bool> result(n);
        for (int i = 0; i < n; i++) {
            result[i] = (candies[i] + extraCandies >= maxCandy);
        }
        return result;
    }
};
```

## Simple Array Sum — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/simple-array-sum/problem)

**Approach**:
Single pass — accumulate the sum of all elements in the array.

**Time**: O(n) | **Space**: O(1)

```cpp
int simpleArraySum(vector<int> ar) {
    int ans = 0;
    
    for (auto val : ar)
    {
        ans += val;
    }
    return ans;
}   
```

## Grading Students — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/grading/problem)

**Approach**:
For each grade of 38 or above, round up to the nearest multiple of 5 only if the remainder when divided by 5 is 3 or more; grades below 38 or with a smaller remainder are left unchanged.

**Time**: O(n) | **Space**: O(1) extra (excluding the output array)

```cpp
vector<int> gradingStudents(vector<int> grades) {
    vector<int> ans;
    ans.reserve(grades.size());
    
    for (auto val : grades)
    {
        if (val >= 38)
        {
            int reminder = val % 5;
            if (reminder >= 3)
                ans.push_back(val + (5 - reminder));
            else
                ans.push_back(val);
        }
        else
            ans.push_back(val);
    }
    
    return ans;
}
```
