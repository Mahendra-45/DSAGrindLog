## Container With Most Water — LeetCode (Medium)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Two Pointer, Greedy
- **Link**: [Problem](https://leetcode.com/problems/container-with-most-water/)

**Approach**:
Two pointers starting at both ends — compute area at each step, then move whichever pointer has the smaller height inward, since it's the limiting factor on area.

**Time**: O(n) | **Space**: O(1)

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int lPoint = 0, rPoint = height.size() - 1, maxWater = 0;
        while (lPoint < rPoint) {
            int width = rPoint - lPoint;
            int ht = min(height[lPoint], height[rPoint]);
            int currWater = width * ht;
            maxWater = max(currWater, maxWater);
            if (height[lPoint] < height[rPoint])
                lPoint++;
            else
                rPoint--;
        }
        return maxWater;
    }
};
```

## Product of Array Except Self — LeetCode (Medium)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Prefix Sum
- **Link**: [Problem](https://leetcode.com/problems/product-of-array-except-self/)

**Approach**:
Two passes without division — first pass fills each index with the product of all elements before it (prefix), second pass multiplies in the product of all elements after it (suffix), accumulated while scanning right to left.

**Time**: O(n) | **Space**: O(1) extra (excluding the output array)

```cpp
class Solution {
public:
    vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size(), suffix = 1;
        vector<int> ans(n, 1);
        // Prefix
        for (int i = 1; i < n; i++) {
            ans[i] = ans[i - 1] * nums[i - 1];
        }
        // Suffix & Answer
        for (int i = (n - 2); i >= 0; i--) {
            suffix *= nums[i + 1];
            ans[i] *= suffix;
        }
        return ans;
    }
};
```
