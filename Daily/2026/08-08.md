## Fizz Buzz — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: Yes
- **Topics**: Math
- **Link**: [Problem](https://leetcode.com/problems/fizz-buzz/)

**Approach**:
Loop from 1 to n, checking divisibility by 15 first (covers both 3 and 5), then 3, then 5, falling back to the number itself as a string if none match.

**Time**: O(n) | **Space**: O(1) extra (excluding the output array)

```cpp
class Solution {
public:
    vector<string> fizzBuzz(int n) {
        vector <string> answer;
        for (int i = 1; i <= n; i++)
        {
            if (i % 15 == 0)
                answer.push_back("FizzBuzz");
            else if (i % 3 == 0)
                answer.push_back("Fizz");
            else if (i % 5 == 0)
                answer.push_back("Buzz");
            else
                answer.push_back(to_string(i));
        }
        return answer;
    }
};
```
