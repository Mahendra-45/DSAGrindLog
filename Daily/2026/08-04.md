## Single Element in a Sorted Array — LeetCode (Medium)

- **Status**: ✅ Solved
- **Revisit**: Yes
- **Topics**: Binary Search, Arrays
- **Link**: [Problem](https://leetcode.com/problems/single-element-in-a-sorted-array/)

**Approach**:
Binary search using the pairing/parity property — since every element appears twice except one, pairs sit at (even, odd) index positions before the single element and shift to (odd, even) after it. Checking whether `nums[mid]` matches its neighbor and whether `mid` is even or odd tells you which half still has the broken pairing, and that's the half to search.

**Time**: O(log n) | **Space**: O(1)

```cpp
class Solution {
public:
    int singleNonDuplicate(vector<int>& nums) {
        int left = 0, right = nums.size() - 1;
        
        if (nums.size() == 1)
            return nums[0]; // If Array has only 1 Element
        while (left <= right) {
            int mid = left + (right - left) / 2;
            // 2 Edge Cases
            if (mid == 0 && nums[0] != nums[1])
                return nums[mid];
            if (mid == nums.size() - 1 &&
                nums[nums.size() - 1] != nums[nums.size() - 2])
                return nums[mid];
            // Ans Element Found
            if (nums[mid - 1] != nums[mid] && nums[mid] != nums[mid + 1])
                return nums[mid];
            if (mid % 2 == 0) { // Even
                if (nums[mid - 1] == nums[mid])
                    right = mid - 1;
                else
                    left = mid + 1;
            }
            else { // Odd
                if (nums[mid - 1] == nums[mid])
                    left = mid + 1;
                else
                    right = mid - 1;
            }
        }
        return -1;
    }
};
```
