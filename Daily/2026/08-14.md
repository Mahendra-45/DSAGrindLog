## Contains Duplicate — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Array, Hash Table, Sorting
- **Link**: [Problem](https://leetcode.com/problems/contains-duplicate/)

**Approach**:
Sort the array first, then scan adjacent elements — if any two neighbors are equal after sorting, a duplicate exists.

**Time**: O(n log n) | **Space**: O(1) extra (excluding sort's internal space)

```cpp
class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        // Array Sorting 
        sort(nums.begin(), nums.end());
        
        for (size_t i = 0; i < nums.size() - 1; i++)
        {
            if (nums[i] == nums[i + 1])
            {
                return true;
            }
        }
        
        return false;
    }
};   
```

**Notes**:
- Backfilled entry
- Tagged Hash Table, but this solution uses sorting instead — a hash-set pass would give O(n) time at the cost of O(n) space, worth trying that variant on revisit
