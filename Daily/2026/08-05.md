## Split Array Largest Sum — LeetCode (Hard)

- **Status**: ✅ Solved
- **Revisit**: Yes
- **Topics**: Binary Search, Arrays, Dynamic Programming, Greedy, Prefix Sum
- **Link**: [Problem](https://leetcode.com/problems/split-array-largest-sum/)

**Approach**:
Binary search on the answer — the search range is from the largest single element (a lower bound, since no subarray can be smaller than the biggest element) to the total sum of the array (the trivial upper bound with 1 split). For each candidate max-sum, a greedy helper checks whether the array can be split into at most `k` subarrays without any subarray exceeding that candidate; the search narrows toward the smallest candidate for which this is possible.

**Time**: O(n log(sum of array)) | **Space**: O(1)

```cpp
class Solution {
public:
    int splitArray(vector<int>& nums, int k) {
        int left = 0, right = 0;
        for (int num : nums) {
            left = max(left, num);
            right += num; // Sum of all elements
        }
        // Binary Search for the Minimum Possible Maximum Sum
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (canSplit(nums, k, mid)) { // If this Max sum works, try smaller
                right = mid;
            } else { // Else we Need larger max sum
                left = mid + 1;
            }
        }
        return left;
    }
    bool canSplit(const vector<int>& nums, int k, int maxSum) {
        int subarrays = 1, currentSum = 0;
        for (int num : nums) {
            if (currentSum + num > maxSum) {
                subarrays++;
                currentSum = num;
                if (subarrays > k) {
                    return false;
                }
            } else {
                currentSum += num;
            }
        }
        return true;
    }
};
```

- Good example of "binary search on the answer" pattern rather than binary search on array indices — worth revisiting to internalize when this pattern applies (usually: monotonic feasibility check + minimize/maximize a value)
