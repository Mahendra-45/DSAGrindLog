## Convert the Temperature — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Math
- **Link**: [Problem](https://leetcode.com/problems/convert-the-temperature/)

**Approach**:
Direct formula application — Celsius to Kelvin by adding 273.15, and Celsius to Fahrenheit by multiplying by 1.8 and adding 32.

**Time**: O(1) | **Space**: O(1)

```cpp
class Solution {
public:
    vector<double> convertTemperature(double celsius) {
        vector <double> ans;
        
        ans.push_back(celsius + 273.15);
        ans.push_back(celsius * 1.8 + 32.0);
        return ans;
    }
};
```

## Simple Array Sum — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/simple-array-sum/problem)

**Approach**:
Single pass — accumulate the sum of all elements in the array.

**Time**: O(n) | **Space**: O(1)

```cpp
int simpleArraySum(vector<int> ar) {
    int ans = 0;
    
    for (auto val : ar)
    {
        ans += val;
    }
    return ans;
}   
```

## Compare the Triplets — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays
- **Link**: [Problem](https://www.hackerrank.com/challenges/compare-the-triplets/problem)

**Approach**:
Single pass comparing both arrays index by index — increment Alice's or Bob's score whichever has the larger value at that position, ties give no points.

**Time**: O(n) | **Space**: O(1)

```cpp
vector<int> compareTriplets(vector<int> a, vector<int> b) {
    int alice = 0, bob = 0;
    
    for (int i = 0; i < a.size(); i++)
    {
        if (a[i] > b[i])
            alice += 1;
        
        if (a[i] < b[i])
            bob += 1;
    }
    return {alice, bob};
}
```

## A Very Big Sum — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Math
- **Link**: [Problem](https://www.hackerrank.com/challenges/a-very-big-sum/problem)

**Approach**:
Single pass summation — uses `long` instead of `int` for the accumulator since the array elements can be large enough that their total sum overflows a 32-bit integer.

**Time**: O(n) | **Space**: O(1)

```cpp
long aVeryBigSum(vector<long> ar) {
    long int ans = 0;
    
    for (auto val : ar)
    {
        ans += val;
    }
    return ans;
}
```

## Diagonal Difference — HackerRank

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Matrix
- **Link**: [Problem](https://www.hackerrank.com/challenges/diagonal-difference/problem)

**Approach**:
Single pass over the matrix — accumulate both diagonals simultaneously using index `i` for the primary diagonal and `size - 1 - i` for the secondary diagonal, then return the absolute difference.

**Time**: O(n) | **Space**: O(1)

```cpp
int diagonalDifference(vector<vector<int>> arr) {
    int diagonal1 = 0, diagonal2 = 0;
    
    for (int i = 0; i < arr.size(); i++)
    {
        diagonal1 += arr[i][i];
        diagonal2 += arr[i][arr.size() - 1 - i];
    }
    return abs(diagonal1 - diagonal2);
}
```
