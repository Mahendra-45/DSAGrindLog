## Two Sum — LeetCode (Easy)

- **Status**: ✅ Solved
- **Revisit**: No
- **Topics**: Arrays, Hashing
- **Link**: [Problem](https://leetcode.com/problems/two-sum/)

**Approach**:
Brute force — check every pair of indices with a nested loop and return the pair whose sum equals the target.

**Time**: O(n²) | **Space**: O(1)

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        for (int i = 0; i < (nums.size() - 1); i++) {
            for (int j = (i + 1); j < nums.size(); j++) {
                if (nums[i] + nums[j] == target) {
                    return {i, j};
                }
            }
        }
        return {};
    }
};
```
